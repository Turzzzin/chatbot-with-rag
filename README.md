# Chatbot with RAG - Medication Information

This project is a web-based chatbot designed to answer questions about medications, using a technique called Retrieval-Augmented Generation (RAG). It was developed as a University Graduation Project (Trabalho de Graduação - TG).

# IMPORTANT RULE
The project is being made for Brazil. Keep all the text in frontend in Portuguese.

## About the Project

The application consists of a Python backend built with **FastAPI** and a simple HTML/CSS/JavaScript frontend.

The core of the project is a RAG pipeline that uses a private dataset of medication information (`DADOS_ABERTOS_MEDICAMENTOS.csv`) to answer user questions.

### How it Works
1.  **Data Processing:** The information from the `.csv` file is processed and its embeddings are stored in a **ChromaDB** vector database.
2.  **Retrieval:** When a user asks a question, the system retrieves the most relevant documents (medication data) from the vector database.
3.  **Generation:** The user's question and the retrieved documents are sent to the **Perplexity AI** language model (`sonar-pro`), which generates a natural language answer based on the provided context.
4.  **Frameworks:** The entire pipeline is orchestrated using the **LangChain** framework.

## Chatbot Capabilities

The chatbot is designed to be a specialized assistant for medication information.

### What the chatbot CAN answer:

The chatbot can provide specific, factual information found in its database, including:

*   **Active Ingredients:** (e.g., "What is the active ingredient of Tylenol?")
*   **Therapeutic Class:** (e.g., "What is the therapeutic class of Losartan?")
*   **Registration Holder:** (e.g., "Which company holds the registration for Neosoro?")
*   **Product Name:** General questions about a medication by its name.
*   **Regulatory Information:** Details like registration number and status.

### IMPORTANT LIMITATIONS: What the chatbot CANNOT do:

The system is explicitly designed with several safety restrictions and will **refuse** to:

*   **Provide Medical Advice:** It cannot give any instructions on how to use a medication, dosages, or treatment plans.
*   **Indicate or Prescribe:** It will not suggest, recommend, or prescribe any medication for any condition.
*   **Diagnose Conditions:** It cannot perform any kind of diagnosis.
*   **Provide Information Outside its Database:** If the answer is not in the provided CSV file, it will state that it doesn't have enough information.
*   **Make Assumptions:** It is programmed not to guess or provide information that isn't explicitly in its knowledge base.

**Disclaimer:** Every answer generated by the chatbot includes a warning that the response was generated by an AI and does not replace the guidance of a healthcare professional.
